# Marketing canon (third-party → this repo)

Read `docs/marketing/00-third-party-marketing-canon.md` before producing or revising marketing work. That file is the imported knowledge. This skill is the enforcement layer.

Product USP and guardrails in `CLAUDE.md` win if they conflict with a tactic in the canon.

## Do not

- Treat this as a rewrite of Wave 1 GTM or as permission to call the product an intake chatbot.
- Spray 19 channels. Use Traction Bullseye: hypothesize, cheap-test, then one core channel.
- Optimize social for likes or weekly lead screenshots. Social is mostly memory for the ~95% out of market.
- Invent conversion rates, or use “cold lead” (reads as lead generation).
- Start a “strategy” with a revenue target and no Rumelt diagnosis.

## Always

1. Name the **one obstacle** the piece removes (Rumelt).
2. Label the piece **brand (95%)** or **activation (5%)**. Do not mash a pitch into thought leadership without a seam.
3. Check **Dunford**: first sentence must trigger the right category assumptions. Wrong frame: “AI receptionist / intake tool.” Right frame: carries an existing inquiry through to a booked consult or accepted quote.
4. Check **JTBD**: progress in circumstances, including anxiety and old habit, not just features.
5. Repeat a **Category Entry Point** and a **distinctive asset** (graphite/bronze/wheel, same verbal hook). New aesthetic every post taxes memory.
6. Prefer proof with a source over adjectives. Hidden buyers need a forwardable argument, not a slogan.
7. Ask whether the work feeds a **loop** (referral, case, search, repeated CEP) or is a one-shot.

## Split of labor

| Layer | Job | Typical artifacts |
| --- | --- | --- |
| Brand / Day 0 | Mental availability, Day 1 List later | LinkedIn/X POV, distinctive assets, CEP stories |
| Activation / Day 1 | Convert in-market 5% | Outreach, trial CTA, sales one-pager, search pages |
| Loop | Output → next input | Design-partner proof → referral, not more top-of-funnel |

Founder outbound works better when the same thesis already exists in public. Do not make a 300-character request explain a new category from zero if a post could have done it last month.

## After writing

Run section 8 of `docs/marketing/00-third-party-marketing-canon.md` as a literal checklist. If an item fails, fix the artifact or explicitly record why the exception is allowed.
