## 5. Ролики — что сказать в камеру

Публичная речь — английский. Сбивка ±10% по словам, не по смыслу. Субтитры 4–6 слов в строке, выжечь в файл. Хук текстом 0–3 с. Музыки нет.

## 6. Какие нейросети задействовать — и какие нет

Авторство = ваше лицо, ваш репозиторий, ваш голос. Мультимедиа нужно, чтобы алгоритм дал dwell (карусель, native video). Не чтобы заменить вас.

### Использовать

| Задача | Чем | Как именно |
| --- | --- | --- |
| Тексты очереди, канон, этот план | **Cursor / Claude в репозитории** | Уже есть. Не просить ChatGPT «написать пост про AI для юристов» мимо очереди |
| Сетка карусели | **Canva Magic Studio** (Magic Design / Resize) | Вставить слайды §4, выставить цвета брендбука. Править кернинг руками. Не «сгенерируй карусель про legal AI» |
| Запас раскладки | **Microsoft Designer** или Figma | Тот же запрет: наш текст, наши цвета |
| Субтитры | **CapCut** auto captions или **Descript** transcription или **Whisper** (local / OpenAI) | Выжечь в файл. 4–6 слов. Жёлтый/белый, не закрывать рот |
| Нарезка ролика | **CapCut** или **Descript** | Обрезать голову/хвост, громкость. Не аватар, не клон голоса |
| Схема цикла | **Claude (Mermaid)** → скрин в Canva, или **tldraw / Excalidraw**, или Canva линии | Коробки и стрелки, не «фото офиса» |
| Чистка кадра экрана | **CleanShot / native crop** | Вырезать URL, PII, `.env` |
| Укоротить подпись | Claude в этом репо | Только ужать уже одобренный `post_text`, не новый сюжет |

Телефонная камера и QuickTime/OBS для экрана — **не нейросеть**, и они главные.

### Не использовать в ленте

| Инструмент | Почему |
| --- | --- |
| HeyGen / Synthesia / D-ID / любой talking avatar | Чужое лицо. Ломает origin 4 сентября |
| Midjourney / Flux / Grok imagine «photo of Alena» | Фейк-фаундер. Сцена это читает |
| ElevenLabs (клон вашего голоса) на посты | Лента должна слышать вас с V-01 |
| Runway / Kling talking head | То же |
| Suno / библиотека TikTok / трендовый звук | Выключает B2B-память |
| Gamma.app «AI deck» как финальный PDF | Типовой стартап-слайд, не графит/бронза |
| ChatGPT / Gemini как автор LinkedIn в обход Table | Другой тезис, часто intake/цена |
| Рерайт Copilot внутри Zap 378524885 | Zap выключен. Не включать |

Абстрактный фон (шум, градиент графит) из генератора — можно на 1% площади, если без людей. Лучше сплошная заливка `#151515`.

Instagram / TikTok / Facebook в сентябре не открываем: некуда резать, пока V-01 не вышел на LinkedIn.
